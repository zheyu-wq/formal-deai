# formal-deai

去除正式书面文本中的 AI 痕迹，同时保持书面语体和正式口吻的 agent skill。

与通用 humanizer 类工具的区别：本技能**严禁口语化、严禁注入个人化表达**，且只做**句级最小修改**、改完**只复检改动句**——专门解决三个常见问题：

1. 降 AI 率时被刻意加入口语，文体垮掉；
2. 每修改一遍又冒出新的 AI 特征（全文重写等于重新掷骰子）；
3. 多轮修改后文风混乱。

## 适用文体

报告、公文、可行性研究、方案、论文、新闻通稿等正式书面文本（中文为主，正式英文亦可）。
随笔、博客等个人文体请改用 [humanizer](https://github.com/blader/humanizer)。

## 工作原理：三条铁律

| 铁律 | 解决的问题 |
|---|---|
| **外科手术**：只改命中特征的句子，一句一换 | 全文重写引入新特征 |
| **基线锁定**：先建风格档案（句长、连接词、标点、称呼、术语），改写句必须服从档案 | 文风混乱 |
| **只查增量**：复检只针对改动句，同一句最多重写两次，否则给候选由人定夺 | 越改越 AI、无限振荡 |

## AI 痕迹清单（中文，13 类）

- **句式**：A1 背景帽子句（"随着……的发展"）、A2 空转强调（"值得注意的是"）、A3 伪递进（"不仅……更"）、A4 三连排比/对仗、A5 升华收尾（"未来可期"）、A6 意义拔高（"标志着……迈入新阶段"）
- **词汇**：B1 AI 高频词堆叠（赋能、助力、彰显、锚定……）、B2 空泛程度副词（极大地、显著地）、B3 同义反复
- **结构**：C1 段头转轮（段段"此外/同时"开头）、C2 机械列举、C3 滥用加粗/emoji、C4 破折号插入语
- **逻辑**：D1 正确的废话、D2 万能归因、D3 虚假范围

每类附改法与《替换方向表》，并设《不该动的》误报区（文体惯例、专业术语、孤立单发不按 AI 痕迹处理）。

另有语域红线：禁止口语化、禁止注入个人化、禁止动事实、**禁止编造**（原文无据的事实标 `【待补：……】` 而非虚构）。

## 安装

将 `SKILL.md` 放入你的 agent skills 目录（如 `~/.agents/skills/formal-deai/`），或按你所用 harness 的 skill 加载方式安装。无依赖、无构建步骤，兼容任何能加载 Markdown skill 指令的 agent。

## 使用

直接对 agent 说，例如：

> 用 formal-deai 处理这篇报告，降 AI 率，保持正式文体。

或模型在听到"降 AI 率""去 AI 味"且文体为正式书面语时会自动触发。

交付物默认为：改动清单（原句 → 改后句 → 命中特征 + 改法）、基线符合性说明、【待补】列表。需要全文时会输出"原文 + 句级替换"的结果，而非重写。
